# История изменений

## 0.1.0

### Добавлено
- Обработка комментариев к записям и коротким видео VK.
- Единый клиентский контекст по VK user ID для ЛС и публичных комментариев.
- Сохранение origin исходного поста/видео, ссылки и доступного медиа.
- Маршрутизация ответа обратно в исходный публичный комментарий.
- Переход из комментария в ЛС без потери клиентского контекста.

- Первый самостоятельный релиз проекта `vk-openclaw-channel`.
- Канал ВКонтакте для OpenClaw на базе VK Bots Long Poll API.
- Поддержка личных и групповых сообщений, медиа, клавиатур, реакций, вопросов агента и нескольких аккаунтов.
- Русскоязычная документация и отдельная структура проекта под сопровождением **mediaprizma**.

### Планируется

- Обработка комментариев к записям на стене ВКонтакте.
- Обработка комментариев к VK Клипа́м.
- Передача агенту контекста записи или клипа.
- AI-анализ комментариев.
- Настраиваемые автоматические ответы.
- Защита от дублирования и зацикливания.
- Модерация, фильтрация и ограничение частоты ответов.

# Руководство по разработке VK Channel for OpenClaw

## Назначение

Этот репозиторий содержит самостоятельный канал OpenClaw для ВКонтакте с идентификатором `vk`.

Проект поддерживает транспорт сообщений через VK Bots Long Poll API и развивается независимо в репозитории `mediaprizma/vk-openclaw-channel`.

## Карта проекта

- `index.ts` — точка входа канала OpenClaw.
- `setup-entry.ts` — точка входа мастера настройки.
- `openclaw.plugin.json` — манифест, схема конфигурации и метаданные канала.
- `src/channel.ts` — основной канал: маршрутизация, состояние и жизненный цикл.
- `src/channel.setup.ts` — поверхность настройки.
- `src/config-schema.ts` — схема конфигурации.
- `src/accounts.ts` — работа с аккаунтами VK.
- `src/monitor.ts` — Long Poll и входящие события VK.
- `src/inbound.ts` — нормализация входящих сообщений и политики доступа.
- `src/send.ts` — исходящая доставка сообщений.
- `src/media.ts` — работа с медиа.
- `src/format.ts` — преобразование Markdown в форматирование VK.
- `src/keyboard.ts` — клавиатуры и кнопки VK.
- `src/question.ts` — вопросы агента и ответы через VK.
- `src/runtime.ts` — runtime-состояние канала.
- `scripts/build.mjs` — сборка TypeScript в `dist`.

## Разработка

Используйте npm:

```bash
npm ci
npm test
npm run build
npm run check:pack
```

Полная проверка:

```bash
npm run check
```

Проверка runtime OpenClaw:

```bash
npm install --no-save --package-lock=false "openclaw@<version>"
npm run build
npm run check:runtime
```

Не создавайте второй lock-файл и не добавляйте в проект отдельный pnpm workspace.

## Принципы изменений

- Сохраняйте совместимость с API канала OpenClaw.
- Не удаляйте `configSchema` из `openclaw.plugin.json`.
- Не храните токены и другие секреты в исходном коде или документации.
- Новые функции должны иметь поведенческие тесты.
- Перед изменениями транспорта сначала проверяйте актуальный OpenClaw SDK и VK API.
- Не ломайте существующую обработку личных и групповых сообщений при добавлении новых типов VK-событий.
- Для комментариев VK предусматривайте дедупликацию и защиту от циклов.
- Изменения пользовательского поведения фиксируйте в `CHANGELOG.md`.

## Направление развития

Основные планируемые расширения:

1. комментарии к записям стены;
2. комментарии к VK Клипа́м;
3. передача агенту контекста публикации;
4. AI-анализ комментариев;
5. автоматические ответы;
6. модерация и фильтрация;
7. защита от повторной обработки и циклов;
8. ограничение частоты автоматических ответов.
